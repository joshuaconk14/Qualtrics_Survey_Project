# Influencer Marketing Analysis

## Project Description

This project is an R Notebook designed to analyze the impact of influencer marketing on purchasing behavior. It utilizes data from a Qualtrics survey and performs logistic regression analysis to understand the relationships between various factors and purchasing decisions.

## Features

- Data loading and preprocessing from Excel files.
- Logistic regression modeling to analyze the influence of marketing channels.
- Visualization of key metrics through histograms.
- Interactive HTML output for easy sharing and presentation.

## Installation

To run this project, you need to have R and RStudio installed on your machine. Follow these steps to set up the environment:

1. Install R from [CRAN](https://cran.r-project.org/).
2. Install RStudio from [RStudio's website](https://www.rstudio.com/products/rstudio/download/).
3. Install the required R packages by running the following commands in your R console:

   ```R
   install.packages(c("readxl", "dplyr", "ggplot2"))
   ```

## Usage

1. Clone this repository to your local machine:

   ```bash
   git clone https://github.com/yourusername/influencer-marketing-analysis.git
   ```

2. Open the R Notebook file `Rstudio mrkting proj.Rmd` in RStudio.
3. Run the code chunks to load the data, perform analysis, and visualize the results.

## Data

The data used in this project is sourced from a Qualtrics survey, which includes various metrics related to influencer marketing and purchasing behavior.
